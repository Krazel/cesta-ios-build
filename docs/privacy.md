# Cesta — privacidad / privacy

Actualizada / Updated: 5 September 2026. Contacto / Contact: coderappskrazel@gmail.com.

## Español

Cesta guarda en el dispositivo tus listas, productos, cantidades, notas, favoritos, ajustes y las fotos que elijas para productos. El selector de fotos permite elegir una imagen; Cesta no necesita acceso a toda tu fototeca, cámara, contactos o ubicación. Esta versión no incluye anuncios, seguimiento publicitario ni herramientas de análisis de uso de terceros.

Cuando el servicio de sincronización está disponible, Cesta envía al servidor el nombre que eliges para identificarte, un identificador técnico del dispositivo y el contenido de las listas, incluidas las fotos incorporadas a sus productos. El servidor guarda estos datos para sincronizar los cambios y permitir que los participantes autorizados usen la misma lista. Una credencial del dispositivo se guarda en el llavero de iOS; el servidor conserva su hash. El servidor utiliza información de conexión temporalmente para limitar solicitudes.

Esta beta utiliza un servidor de pruebas en la red local. Las personas con acceso al servidor pueden administrar los datos. Los participantes de una lista compartida pueden ver su contenido y nombre de participante. No se envían estos datos a proveedores de publicidad o análisis. Apple gestiona por separado la distribución, comentarios e informes de fallos de TestFlight según sus propias condiciones de privacidad.

Puedes editar o eliminar productos y, si eres propietario, eliminar una lista compartida. Salir de una lista retira tu acceso, pero no elimina la lista de los demás. Retirar una lista de Inicio solo la guarda. Los datos técnicos de registro, las copias exportadas y las copias ya conservadas por otras personas no se eliminan al retirar una lista; puedes solicitar ayuda para eliminar datos del servidor mediante el contacto indicado. Los datos del servidor se conservan hasta su eliminación o cierre de la beta; no hay un plazo de borrado automático. Las copias que exportes o compartas quedan bajo tu control y el del destinatario.

## English

Cesta stores lists, products, quantities, notes, favourites, settings and product photos you select on your device. The photo picker lets you choose an image without requiring full photo-library, camera, contacts or location access. This version has no advertising, advertising tracking or third-party usage analytics.

When the sync service is available, Cesta sends your chosen display name, a technical device identifier and list content, including attached product photos, to the server. The server stores this information to synchronize changes and give authorized participants access to shared lists. A device credential is stored in the iOS Keychain; its hash is stored on the server. Connection information is used temporarily for request limiting.

This beta uses a test server on the local network. Server operators can administer the data, and shared-list participants can see list content and participant names. This data is not sent to advertising or analytics providers. Apple separately manages TestFlight distribution, feedback and crash reports under its privacy terms.

You can edit or remove products and delete shared lists you own. Leaving a list removes your access without deleting it for others. Removing a list from Home only saves it. Technical registration records, exported backups and copies retained by others are not erased by removing a list; contact the address above for help deleting server data. Server data remains until deleted or the beta closes, with no automatic deletion period. Exported and shared copies are controlled by you and their recipients.
